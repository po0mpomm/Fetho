# Fetho

A creative production studio and transformative educational ecosystem web experience crafted with Three.js, WebGL, and GSAP.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+)

### Installation
```bash
npm install
```

### Run Locally
```bash
npm start
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

## Pages
- **Homepage:** `http://localhost:3001/`
- **Career & Life:** `http://localhost:3001/career-life.html`
- **Venture Lab:** `http://localhost:3001/venture-lab.html`
